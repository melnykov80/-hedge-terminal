Hedge Terminal

Personal crypto trading terminal for Bybit USDT-perpetuals (DCA / mean-reversion strategies).
Personal project · single user · not a commercial product · no resale

Features

  • Real-time chart with Bybit v5 REST + WebSocket via a custom Datafeed
  • KLineChart engine: chart types, 40+ indicators, 30+ drawing tools, 10 timeframes
  • Drawing & indicator legends (show / hide / settings / delete)
  • DCA bot drawer: exchange, searchable pair picker, strategy, margin, leverage, TP/SL, risk
  • Watchlist with all USDT futures of the selected exchange (Bybit / Binance / OKX / Bitget)
  • Light & dark theme
FrontendReact 18 · TypeScript · Vite
ChartKLineChart 10 · react-klinecharts-ui
DataBybit v5 public REST + WebSocket
WatchlistBybit · Binance · OKX · Bitget
Personal use, in active development. Not deployed publicly.
